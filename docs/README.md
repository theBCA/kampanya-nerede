# Fiyatı Ne Docs

This repo keeps committed product decisions separate from raw research exports.

## Structure

- `docs/product/` - user-facing product decisions and MVP scope
- `docs/market/` - competitor examples and market positioning
- `docs/technical/` - architecture, data model, and build sequencing
- `docs/mvp-v1.md` - short executive MVP summary
- `docs/name-ideas.md` - naming notes

## Ignored source material

Raw `.docx`, exported research HTML, pasted notes, and the local `context/` folder are intentionally ignored by git. They are useful as working context, but they should not become the clean project source of truth.

The current source of truth for building is:

1. `docs/product/mvp-spec.md`
2. `docs/technical/architecture.md`
3. `docs/market/real-website-examples.md`
4. `fiyati-ne-mvp.html`
